# 证据缺口与定向补查

目前支持五类有边界的属性缺口：票价/免费适用条件、直飞航线、明确事件时间、明确数量，以及全称/限定范围。其余类型保留现有判定逻辑，不声称已完成通用自然语言蕴含验证。

规则判定与Agent综合共享缺口检查。它只看当前引用来源的实际摘要和已抓取正文，不用重复标题充当证明。开放时间不能证明免票，航站楼开放不能证明某条直飞航线。

**缺口只做标注，不做裁决。** 命中缺口时只在 `ClaimResult.evidence_gaps` 里记录并追加说明，`verdict`、`confidence`、`truth_probability`、`correction` 全部保持规则或 LLM 判定器给出的原值，既不向 `insufficient` 降级，也不因关键词出现而提升真假结论。原因是这里的识别器只是有限领域的关键词/正则探针：没匹配上只能说明"这批模式没找到对应原文"，不等于"证明不存在"，用它直接改判会在正则覆盖不到的表述上产生系统性误判。缺口的作用是驱动下一轮定向补查，并把"这条属性没有原文支撑"如实暴露给用户和判定器。

每条 `ClaimResult.evidence_gaps` 包含属性维度、缺口描述和查询建议。深度路径的逐claim补查优先使用这些建议；即使当前 verdict 是 `supported`、`refuted` 或 `conflicting`，事实型声明存在缺口时也会进入有界补查，未命中上述属性而判为 `insufficient` 的事实声明也仍可进入通用逐条检索。每轮最多选三条，优先未补查的声明；补查继承原请求的检索来源及缓存限制，跨批次证据ID单独命名并只在同一URL时复用已有ID，保留不同来源中更权威的原文；子集重判不丢失其他声明的证据，判定、信心与引用均不变且新判定器未给出概率时保留原概率。重判后仍缺材料则保留缺口。快速路径不增加网络补查。既有轮次限制、持久run调用预算和用户停止信号共同限制继续执行，不为了结束任务而强行给出确定结论。

已有正文里的完整短句会保留，即使它与标题文字相同。航线检查对起讫地点作对应，去除“机场”“已经开通”等语法修饰，不能把其他目的地的航班当成证据。

## 时间、数量和范围的识别边界

- 时间：识别 `2024年`、`2024年5月1日`、`2024-05-01`、`2024/05/01` 等明确日期，以及同一分句中的对应事件动作。支持成立/设立、生效/实施、开通/停运、营业/停业、开放/闭馆、招聘/裁员、停课/复课、召回等有限词表；网页发布日期、与事件无关的日期不能填补缺口。
- 数量：识别阿拉伯数字或常见中文数字与人数、门店数量、岗位数量、产品件数/批次的组合，并要求同一分句含对应动作和同类单位。招聘人数不能由门店数、年份填补；不把百分比、编号、金额、模糊数量强行解释为人数。
- 范围：识别“所有、全部、全都、都是、全是、均为、仅招聘、只招聘、只招”等限定词及门店、店铺、分店、岗位、员工、学校、产品等对象。覆盖材料需在同一分句中指明对应对象、动作及全体或明确例外。“只有部分门店停业”覆盖范围并可供既有判定器反驳全称声明；单独“部分门店停业”不证明其他门店没有停业，仍保留范围缺口。

匹配的是**属性有没有原文材料**，不是属性值与声明是否一致。声明说2024年成立，而原文说2023年成立；声明招聘100人，而原文说只招聘50人或没有招聘；声明所有门店停业，而原文说只有部分停业——这些都不因值不同而产生缺口。属性覆盖与否都不改变既有判定，缺口只是标注和补查依据。

以上三类只处理包含单一可识别动作组的声明；多事件复句、相对时间、未识别日期/单位、隐含范围及需要跨句指代消解的材料仍有边界。明确位于声明开头、带公司/集团/大学/医院/博物馆后缀的非泛称主体，需要在原文同句出现，且不得借逗号后其他显式主体的属性填补；这里只是属性匹配约束，不新增通用主体识别或 `entity` 缺口。标题、模型改写摘要和 `stance_quote` 不能代替实际检索摘要/抓取正文。

用户复核范围由父报告确定。当前缺口规则不会把观点、预测或不可核实声明变成事实判断；没有生成对应结果时，以原类型和证据不足占位，并保留旧版本供查阅。
