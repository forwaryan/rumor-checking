# 抓取、缓存与执行安全边界

## 统一公开网页抓取

普通 URL 提取、Agent 正文抓取、判定器补正文和补充链接共用 `reliable_get`：

- 每个重定向目的地重新校验 HTTP(S) URL、凭证字段和全部 DNS 地址；DNS 失败、混合公网/非公网地址及组播地址均拒绝。
- 连接固定到本跳已验证的公网 IP，保留原域名 Host 与 TLS SNI，启用证书校验。禁用环境代理，每跳使用独立 Client，不传播 Cookie、Authorization 或来源页面的敏感请求头。
- 最多六跳，每次逻辑请求最多四次尝试，仅重试临时网络错误及 5xx。4xx、安全校验失败、体积/编码拒绝均不重试。
- 流式读取原始响应，单响应最多 2 MiB，声明长度与分块累计长度都检查，超限立即关闭。发送 `Accept-Encoding: identity`，拒绝仍返回压缩编码的服务器，避免先解压后检查带来的内存膨胀。

`URL_FETCH_MAX_CHARS` 仍控制后续提取字符数，不代替下载体积限制。抓取失败保守降级，不能为了保住来源数量而绕过公网或大小检查。无法建立公网直连、仅支持压缩返回、需要登录的页面可能无法使用。

## 可选浏览器 fallback

`RENDERED_FETCH_ENABLED` 默认仍关闭。开启后，GET HTTP(S) 请求由上述安全传输取回，再通过 Playwright `route.fulfill` 提供给页面，不放开浏览器直接抓取。

浏览器使用不可连接的代理端点及限制直接解析/QUIC/非代理 WebRTC 的参数，阻断 Service Worker 和 WebSocket。不能建立安全路由的版本或非 POSIX 环境返回 `safety_unavailable`，不会退回不受控连接。HTTP 重定向、POST 等不支持的情况会明确降级。

单次渲染最多 32 次请求、累计响应正文 4 MiB、输出 HTML 2 MiB、截止预算上限 15 秒（清退时间另计）。独立进程负责浏览器操作，父进程负责截止、取消和清退。启动采用 ready/ack 握手，非阻塞 IPC 入站上限为 2 MiB + 71 字节，半帧等待期间仍检查截止；清理已确认的进程组，不因 leader 先退出就遗留浏览器。这些是纵深防护，不是完整 OS 网络/内存沙箱；公开部署仍需要出口隔离。

## 复核的新鲜度

复核绕过判定缓存、检索缓存及正文缓存，并禁止检索失败后偷偷回退过期材料；继承的 `retrieval_cache_only` 不覆盖复核刷新策略。获取失败就按现有材料不足处理，旧版仍可查看。

普通请求保留原有缓存策略。`URL_FETCH_CACHE_ENABLED=false` 对 Agent 抓取和 `page_fetcher` 都禁止读写。显式绕过检索缓存时，失败分支也不读取旧缓存。

判定缓存仍默认关闭；启用时使用版本化的输入、请求策略及模型/来源配置指纹，不再仅按文本复用整份报告。运行 ID 不影响复用，mock、补证、复核请求不读写判定缓存；旧文本键自然失效。

## 超时不是遗留线程放行

单 Agent 调用或多 Agent 批次超过其执行截止时，共享控制器以 `agent_timeout` 及时把持久任务标记为停止，拦截后续请求、事件、重试及最终报告发布。

已发出的同步调用和任意阻塞 Python 函数无法被线程安全地强杀，因此工作线程仍需清退；期间继续持有原 run 的执行锁并占用容量。不能用 `shutdown(wait=False)` 让旧线程与恢复/新任务同时操作同一状态。看到“已停止”不代表某个已发出的远程请求已经被撤回。

## 兼容 API 与输入限制

`POST /analyze` 和 `POST /analyze/stream` 通过同一个 `AnalysisRunManager` 执行，共享容量、持久模型预算、停止及记录保留策略。同步接口仍返回 Report，流式接口仍返回平铺 NDJSON（包括心跳），响应头 `X-Analysis-Run-ID` 标识对应持久任务。同步任务因 Agent 超时停止时返回 504，其他停止返回 409；容量不足返回 429。

关闭兼容流也不自动取消后台运行，可通过对应 run 的取消接口停止。新客户端仍建议直接使用持久任务 API。

所有分析入口的 `raw_input` 最多 100,000 个 Unicode 字符，超过返回 422。写请求完整 JSON 最多 1 MiB，包含其他字段；框架解析前检查声明长度及实际分块体积，超限返回 413，读取请求体超过 30 秒返回 408。前端会提示并阻止超长输入，不静默截断原文。

Next 代理对声明长度执行相同的前置检查，避免后端提前拒绝时代理写入失败而将 413 改成 500。没有声明长度的分块请求仍由后端按实际字节数检查；部署网关也应配置相应的上传大小限制。

## 验证边界

回归使用受控 DNS/HTTP/浏览器替身、真实 TLS 参数检查及可控阻塞线程，不向真实内网或第三方站点进行攻击验证。普通测试阻止未录制的非本机网络连接；确需联网的测试须标记 `slow`。

这些修复不新增账号鉴权、用户级配额、分布式 worker 或永久案例库。公开部署的认证网关和出口策略仍是独立要求。
