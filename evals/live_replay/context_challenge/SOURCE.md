# Context challenge regression set

Eight explicitly synthetic, manually reviewed fixtures add missing evaluation
dimensions. They contain two supported, two refuted, two insufficient, and two
conflicting claims. Every name, event, publisher and `.example` URL is fictional.

The insufficient cases contain related authoritative material that does not
answer the asserted attribute. They must not be labelled false merely because
an opening-hours notice omits ticket prices or a terminal notice omits routes.
Conflict cases align entity, time and counting scope and require both opposing
sources. Two supportive cases include independent firsthand observations.

Cases 001, 004, 005 and 007 belong to `development`; 002, 003, 006 and 008 belong
to `holdout`. Each partition contains one case per verdict. Topic groups are
disjoint, and no split is an official external benchmark split. This small
handcrafted set is a coverage guard, not a production accuracy estimate.

Review date: 2026-09-13. Annotation rationale, information origin and evaluation
partition are recorded in each JSON file. The whole set must be versioned and
reported independently of CFEVER and the historical health-rumor corpus.
